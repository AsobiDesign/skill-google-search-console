# ディメンション・メトリクス分析

Google Search Console（Search Analytics API）の主要ディメンションとメトリクスの一覧。すべての分析はこの組み合わせが起点になる。

## メトリクス

### クリック数（clicks）

#### 定義
検索結果からサイトへ実際にクリック（流入）された回数。

#### 用途
検索経由の実際の集客量を示す。期間比較で増減を見て、SEO施策や新規コンテンツの効果を判断する。

#### 取得パラメータ
`gsc_query.py` の出力に常に含まれる（`clicks`）。ディメンション指定は任意。

### 表示回数（impressions）

#### 定義
検索結果にサイトのURLが表示された回数（クリックの有無を問わない）。

#### 用途
検索需要そのものの規模を示す。表示回数が多いのにクリックが少ない場合はタイトル・スニペットの魅力不足が疑われる。

#### 取得パラメータ
`gsc_query.py` の出力に常に含まれる（`impressions`）。

### クリック率（ctr）

#### 定義
クリック数 ÷ 表示回数。検索結果一覧でどれだけ選ばれているかを示す。

#### 用途
掲載順位のわりにCTRが低いクエリ・ページは、タイトルタグやメタディスクリプションの改善余地がある。逆に掲載順位が低いのにCTRが高いクエリは、コンテンツ自体の訴求力が強いサインなので上位表示できれば大きく伸びる。

#### 取得パラメータ
`gsc_query.py` の出力に常に含まれる（`ctr`、0〜1の小数）。

### 掲載順位（position）

#### 定義
検索結果におけるサイトの平均表示順位。数値が小さいほど上位。

#### 用途
1ページ目（1〜10位）に乗っているか、2ページ目以降（11位以下）に埋もれているかで打ち手が変わる。11〜20位は「あと一歩」の圏内で、コンテンツ強化により1ページ目浮上を狙いやすい。

#### 取得パラメータ
`gsc_query.py` の出力に常に含まれる（`position`）。

## ディメンション

### 検索クエリ別（query）

#### 定義
ユーザーが実際に検索した語句ごとの実績。

#### 用途
どのキーワードで流入しているか、伸ばしたいキーワードでの現在地を把握する。指名検索（ブランド名）と非指名検索（一般キーワード）を分けて見ると集客の質が分かる。

#### 取得パラメータ
`--dimensions query`

### ページ別（page）

#### 定義
検索結果に表示された自サイトのURLごとの実績。

#### 用途
どのページが検索流入の主力かを把握する。トップページ以外で流入しているページ（商品ページ・特集ページ等）はSEOの入口として重要。

#### 取得パラメータ
`--dimensions page`

### 国別（country）

#### 定義
検索を行ったユーザーの所在国ごとの実績。

#### 用途
海外流入の有無・規模を確認する。国内向けECサイトで海外比率が異常に高い場合は不要なクロール・スパムアクセスの可能性もある。

#### 取得パラメータ
`--dimensions country`

### デバイス別（device）

#### 定義
検索を行ったデバイス種別（DESKTOP / MOBILE / TABLET）ごとの実績。

#### 用途
モバイルとデスクトップでCTRや掲載順位に差がある場合、モバイル表示の使いやすさやページ速度に問題がないか確認する。

#### 取得パラメータ
`--dimensions device`

### 日付別（date）

#### 定義
日ごとの実績。時系列の推移を把握するために使う。

#### 用途
クリック数・表示回数の推移をグラフ化し、急落・急増のタイミングを特定する。アルゴリズムアップデートやサイト変更のタイミングと突き合わせて原因分析する。

#### 取得パラメータ
`--dimensions date`（他のディメンションと組み合わせて `--dimensions date,query` のように時系列×属性のクロス集計も可能）

## 掲載順位改善余地の見つけ方

Search Console分析で最も価値が高いのは「伸びしろのあるクエリ・ページ」の発見。以下のパターンで抽出する。

| パターン | 条件の目安 | 意味 | 打ち手 |
|---|---|---|---|
| CTR改善余地 | 表示回数が多い（上位）のにCTRが低い（平均以下） | 検索結果には出ているが選ばれていない | タイトルタグ・メタディスクリプションの改善、構造化データ（レビュー星等）の付与 |
| 1ページ目浮上の余地 | 掲載順位11〜20位、かつ表示回数がある | 惜しいところまで来ている | 対象クエリを意識したコンテンツ強化、内部リンク追加、E-E-A-T強化 |
| 掘り起こし余地 | 掲載順位21位以下だが表示回数がある | 検索需要はあるが評価が低い | ページの新規作成・大幅リライトを検討 |
| 伸びているクエリ | 期間比較でクリック数・表示回数が増加 | 現在うまくいっている領域 | 関連キーワードでのコンテンツ拡充、広告と連動したさらなる強化 |
| 落ちているクエリ・ページ | 期間比較でクリック数・掲載順位が悪化 | 何らかの問題が発生している | 該当ページの内容鮮度・被リンク状況・競合の変化を確認 |

## ユーザーリクエスト → 参照ディメンション/メトリクス

| リクエスト | ディメンション | 主なメトリクス |
|---|---|---|
| 検索クエリ別の実績、どんな言葉で検索されているか | query | clicks, impressions, ctr, position |
| ページ別の検索流入、どのページが強いか | page | clicks, impressions, ctr, position |
| 掲載順位、検索順位、順位改善 | query または page | position, impressions |
| CTR、クリック率、選ばれていない | query または page | ctr, impressions, position |
| 表示回数、インプレッション、検索需要 | query または page | impressions |
| 海外流入、国別のアクセス | country | clicks, impressions |
| スマホ/PCでの見え方の差、デバイス別 | device | clicks, ctr, position |
| 検索流入の推移、日別の変化、急落・急増 | date（+ query/page） | clicks, impressions |
| SEO全般、オーガニック検索の状況 | query, page | clicks, impressions, ctr, position |
