# テキスト出力

会話内で直接テキストとして報告する。

## 構成

### サマリー

3分で説明できる「結果と次のアクション」をまとめる。意思決定に必要な情報だけを抽出し、全員に同じ内容を正確に伝える。

| セクション | 内容 |
|---|---|
| 3大ポイント | 今期の結果から最も重要な3つの発見を箇条書きで示す |
| ゴールとKPI | クリック数・表示回数・平均CTR・平均掲載順位などの実績値と目標値を並べ、達成度を示す |
| やるべきこと | 分析結果から導かれる具体的なアクション項目を優先度順に示す |

### 数値×施策レポート

数値だけでは施策の効果判断ができない。数値と施策情報を並べ、何が数値を動かしたかを読み取れるようにする。

| 要素 | 内容 |
|---|---|
| 数値 | テーブルによる数値推移（クリック数・表示回数・CTR・掲載順位） |
| 施策 | 指標ごとに施策一覧（タイトル改善・コンテンツ追加・内部リンク強化など、実施済み・予定） |

施策と数値を並べることで、施策が数値に与えた影響を把握でき、次の打ち手の判断材料になる。

### 改善施策の提案

施策提案では「精度ではなくロジック」を重視する。過去の実績データを根拠に効果を換算し、クリック数・順位インパクトを数値で示す。

| ルール | 内容 |
|---|---|
| 根拠を示す | 過去実績から効果を算出する（例:「掲載順位が11位から8位に改善すると表示回数の同水準でクリック数が月150件増」） |
| 選択肢を出す | 施策案を複数提示し、それぞれの期待効果と優先度を示す |
| 曖昧にしない | 「やってみないとわかりません」は避け、ロジックで説明する |
